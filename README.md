# AIM TRAINER

Браузерная тренировка реакции с локальным и общим рейтингом.

## Что работает сразу

- раунд 30 секунд;
- случайные цели;
- попадания, промахи, точность и средняя реакция;
- локальная таблица лидеров в браузере;
- адаптивный интерфейс.

## Как включить общий рейтинг

1. Создай проект в Supabase.
2. Открой **SQL Editor**.
3. Выполни содержимое файла `supabase_setup.sql`.
4. В Supabase открой **Project Settings → API**.
5. Вставь `Project URL` и `anon public key` в `config.js`.
6. Не используй `service_role key` — он секретный.
7. Сохрани изменения и дождись обновления GitHub Pages.

Пока Supabase не настроен, игра автоматически показывает локальный рейтинг.

## GitHub Pages

В настройках репозитория открой **Settings → Pages**, выбери публикацию из ветки `main` и папки `/root`.
